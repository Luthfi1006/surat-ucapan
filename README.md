## 🚀 Cara Deployment

1. Buka [app.netlify.com/drop](https://app.netlify.com/drop)

### GitHub Pages
1. Pastikan repo sudah di-push ke GitHub.
2. Aktifkan **GitHub Pages** di menu *Settings* repositori Anda.
