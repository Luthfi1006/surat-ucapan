Folder assets/
----------------
Kamu bisa menaruh foto-fotomu bersama pacar atau lagu favorit kalian di folder ini:

1. Foto:
   - Taruh foto di sini (misal: "foto1.jpg", "foto2.jpg", dst).
   - Di file config.js, ganti URL foto menjadi: "assets/foto1.jpg".

2. Lagu Romantis:
   - Taruh file MP3 di sini (misal: "lagu.mp3").
   - Di file config.js, ubah bagian music -> url: "assets/lagu.mp3".
